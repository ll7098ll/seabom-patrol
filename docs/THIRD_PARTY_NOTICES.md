## 프로젝트 자체

기준 작업 폴더에는 프로젝트 전체에 적용되는 LICENSE 파일이 없었습니다. 이 업로드용 묶음에서도 저작권자 확인 없이 MIT 등의 프로젝트 라이선스를 새로 부여하지 않았습니다. 공개 저장소 게시와 재사용 허락 범위는 구별되며, 이용 조건을 정할 때 권리자가 별도 LICENSE를 추가해야 합니다.

## 동봉 글꼴

Pretendard Variable은 public/fonts/PretendardVariable.woff2로 동봉됩니다. 저작권 표기와 SIL Open Font License 1.1 원문은 [public/fonts/LICENSE.txt](../public/fonts/LICENSE.txt)를 그대로 유지합니다. Copyright (c) 2021, Kil Hyung-jin, Reserved Font Name Pretendard.

## 가상 자료와 기존 화면

도시 수치·사건·시설·주민 발언은 가상 자료라는 원본 설명을 유지합니다. public/legacy/는 이전 앱 보존본입니다. 브랜드 SVG와 프로젝트 작성 코드에 별도 외부 라이선스를 임의로 붙이지 않았습니다.

작업 폴더의 SKT 뉴스 영상과 외부 참고 미디어는 업로드 대상에 포함하지 않았습니다. README의 화면 이미지는 이 패키지를 로컬 실행한 화면입니다.
