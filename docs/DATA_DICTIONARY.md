## 기준과 기간

현재 앱이 읽는 원본은 [public/data/saebom-city.json](../public/data/saebom-city.json)입니다. meta.synthetic는 true이며 인구·사건·시설 수치는 수업용 가상 도시 모형으로 생성되었습니다. 실측 자료나 실제 주민 인터뷰가 아닙니다.

| 항목 | 값 |
|---|---|
| 자료 버전 | 3.0 |
| 관찰 기간 | 2026-09-14~2026-10-11, 28일 |
| 운영 비교 기간 | 2026-10-12~2026-10-18, 7일 |
| 좌표 | SAEBOM_LOCAL_METRES, 가상 로컬 미터 좌표 |
| 지도 범위 | 가로 6,000m × 세로 4,000m |
| 격자 | 200m × 200m, 총 600칸; 강을 포함한 칸은 land_fraction 확인 |
| 발생시각 | ISO 8601, +09:00 |
| 생성 시드 | 2026102607 |

이 좌표는 위도·경도가 아닙니다. 실세계 지도 위에 그대로 겹치면 안 됩니다. 동네 8개와 차량별 전담 구역 10개는 서로 다른 구분입니다.

## 요청·도로·배치의 핵심 필드

| 객체 | 필드 | 의미 |
|---|---|---|
| 요청 | id, zone_id, cell_id, xy | 식별자, 동네, 격자, 미터 좌표 |
| 요청 | received_at, priority | 발생시각, urgent 등 긴급도 |
| 요청 | dispatch_required, required_units | 차량 출동 여부, 필요 차량 수 |
| 요청 | handling_delay_s | 접수 처리 시간, 초 |
| 요청 | on_scene_minutes, paperwork_minutes | 현장·서류 처리 시간, 분 |
| 도로 | from, to, geometry, length_m | 연결 노드, 선 좌표, 길이 |
| 도로 | direction, modes | 양방향/정방향/역방향 통행과 교통수단 |
| 도로 | speed_kph, time_factors, junction_delay_seconds | 제한속도, 혼잡 배율, 교차로 지체 |
| 차량 배치 | id, edgeId, f | 차량 번호 1~10, 도로 ID, 구간 내 비율 0~1 |

requests 1,120건 중 dispatch_required인 965건을 시뮬레이션에 사용합니다. 출동이 없는 안내·연결 요청을 누락된 출동으로 집계하지 않습니다. 현장·서류 시간은 원자료를 그대로 사용하며 누락됐을 때만 명시한 시드의 가정값을 사용합니다.

## 자료 해석

대표 하루 평균 인원과 28일 누적 건수는 기간과 단위가 다릅니다. 설문은 생활권별 자발적 응답의 가상 표본으로 도시 전체의 대표 추정이 아닙니다. 주민 발언은 개인 경험이며 수치 점수를 부여하지 않습니다.

이 패키지는 실행에 쓰는 확정 JSON을 제공합니다. 이전 작업 폴더의 자료 생성·보정 스크립트와 중간 원본은 포함하지 않으며, 모든 생성 과정을 재실행하는 원본 묶음은 아닙니다.
