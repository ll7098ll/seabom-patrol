# 학생 사용 안내

[README로 돌아가기](../README.md)

## 1. 도시 관찰

첫 화면에서 도움 요청과 확인된 사건을 살펴봅니다. 도움 요청은 교통·안전·안내 등을 포함하므로 확인된 사건 수와 같지 않습니다.

- ‘도움과 사건’, ‘사람과 돌봄’, ‘출동하는 길’, ‘주민의 경험’ 미션을 선택하면 관련 자료를 함께 볼 수 있습니다.
- 자료 목록에서 레이어를 켜거나 끕니다. 수량 자료의 표현과 진하기는 자료별로 조절합니다.
- 지도에서 장소를 누르면 그 200m칸의 자료를 살펴볼 수 있습니다. ‘근거로 담기’로 자료와 관찰 이유를 보관합니다.
- 같은 장소를 다시 담으면 자료를 합칩니다. 서로 다른 장소는 최대 16개이며 이유는 240자까지 저장합니다.
- 주민 발언은 개인의 가상 경험입니다. 숫자로 순위를 매기거나 동네 전체의 생각으로 해석하지 않습니다.

## 2. 차량 10대 직접 배치

‘관찰 마치고 배치하기’를 누릅니다. 이 단계가 열리려면 앞 단계의 완료 버튼을 눌러야 하며, 관찰 근거를 반드시 일정 개수 작성해야 하는 것은 아닙니다.

차량 번호를 선택하고 도로를 누르거나 이미 놓은 차량을 끌어 옮깁니다. 도로에서 너무 멀거나 차량이 다닐 수 없는 곳에는 배치할 수 없습니다. 배치점은 전담 구역을 정하는 기준이며 차량이 계속 서 있는 대기소를 뜻하지 않습니다.

선택한 차량의 구역과 점선 순찰 코스를 확인하세요. 차량을 한곳에 겹치면 일부 구역이나 순찰 경로가 없어질 수 있습니다. 경고가 나타나면 위치를 조정합니다. 예시 배치·한곳에 모으기·비우기·되돌리기를 사용할 수 있습니다.

비교 출발점을 보관하려면 10대를 놓고 기준 배치로 저장합니다. 기준을 따로 저장하지 않았다면 앱에 들어 있는 분산 예시와 비교합니다.

## 3. 운영 재생과 비교

10대를 모두 배치한 뒤 ‘배치 마치고 운영 재생’을 누릅니다. 현재 배치와 기준 배치를 같은 요청으로 계산합니다.

- 시계는 10월 12일 00:00부터 시작합니다. 신고는 원자료 발생시각에 나타납니다.
- 재생·일시정지, 처음부터, 날짜 이동, 다음 신고, 시간 앞뒤 이동과 30×·60×·240× 속도를 사용할 수 있습니다.
- 접수 처리, 배정 대기, 출동 준비·이동, 현장 처리, 복귀와 순찰을 구분해서 읽습니다.
- 아직 도착하지 않은 신고는 완료된 도착시간으로 읽지 않습니다. 일주일 전체 결과는 별도로 펼쳐 확인합니다.
- ‘거리만 비교’는 한 요청에 대한 경로 비교입니다. 차량이 여러 사건을 처리하는 ‘동시 출동 검증’과 계산 조건이 다릅니다.
- 위치를 바꾸면 이전 결과는 현재 배치의 결과가 아닙니다. 운영을 다시 계산하세요.

## 4. 기록 보관

탐구 기록 창에서 배치와 근거를 JSON 파일로 내보내고, 같은 버전의 JSON을 불러올 수 있습니다. 최대 1MB의 파일을 받으며 자료 형식과 도로 위치를 확인합니다.

자동 저장에는 현재 배치·기준 배치·선택 정보·관찰 근거가 포함됩니다. 재생 결과와 관찰 단계 완료 상태는 재접속 시 다시 준비해야 합니다. 브라우저 기록 삭제, 시크릿 모드 종료, 주소 변경으로 저장 자료가 달라질 수 있으므로 수업을 마치기 전에 JSON 파일을 보관하세요.

내보내는 이유 글에는 본인이나 다른 사람의 개인정보를 적지 마세요. 이 React 버전의 내보내기는 JSON이며 이전 사이트의 HTML 탐구 기록과 형식이 다릅니다.

## 자주 생기는 문제

| 상황 | 해결 |
|---|---|
| 배치 단계가 비활성화됨 | ‘관찰 마치고 배치하기’를 누릅니다. |
| 운영 버튼이 비활성화됨 | 차량이 10대 모두 배치되었는지 확인합니다. |
| 몇몇 구역의 신고가 계속 대기함 | 담당차 대기 정책과 해당 차량의 업무량을 확인합니다. |
| 구역이 너무 작거나 순찰 코스가 없음 | 겹친 배치·단방향 도로를 살피고 위치를 바꿉니다. |
| 다른 컴퓨터에 기록이 없음 | 이전 기기에서 JSON을 내보낸 뒤 불러옵니다. |
| ‘이전 사이트’ 화면이 다름 | 보존한 이전 버전입니다. 현재 버전의 규칙·기록과 구별합니다. |
